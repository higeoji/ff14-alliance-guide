天然要害 サスタシャ浸食洞

道中・進行のポイント

  1. 開始後、最初の行き止まりにある【薄汚れたメモ】を調べ、「赤・青・緑」のどの色が書かれていたか覚える。
  2. ジャイアントクラムは開いている間に攻撃する。放置するとシェイド・シーカーを出し続けるので、戦う場合は貝を優先。
  3. 最初のボス前では、メモと同じ色の珊瑚を調べる。正解すると【扉のスイッチ】が出現する。
  4. 間違った色の珊瑚を調べると毒＋雑魚出現。総当たりせずメモの色を使う。
  5. 船長戦後の広場では敵が落とす【船長室の鍵】を拾い、船長室へ入る。
  6. 船長室内の敵を倒して【海人門の鍵】を入手し、海人門を開けて先へ進む。
  7. 広場は分岐が多いが、目的は鍵回収→船長室→海人門。宝箱目的でなければ不要な部屋へ入らなくてよい。

BOSS 1チョッパー

  1. 【チャージドホイスカー】ボス中心範囲。被弾すると麻痺するので外へ離れる。
  2. ボス前は「薄汚れたメモ」の色に対応する珊瑚を調べ、正解のスイッチを出す。
  3. 誤った珊瑚を選ぶとケーブ・オーレリアが出現するため、メモを確認すると確実。
  4. チャージドホイスカーはスタンでも止められるが、基本は範囲外へ退避でよい。
  5. 低レベルで移動猶予が長いので、詠唱確認後に攻撃を止めて確実に離れる。

BOSS 2マディソン船長

  1. 1回目・2回目とも護衛付き。タンクは護衛もまとめて保持する。
  2. 【ヘビースイング】ヘイト1位への追加物理攻撃。タンクは正面を味方へ向けない。
  3. 2回目は【ファストブレード】も使用。単体攻撃なのでヒーラーはタンクHPを確認。
  4. 【サンドスリンガー】命中率低下を付与する単体攻撃。必要ならエスナで解除する。
  5. 2回目はHP50%付近でスカヴィ・ドッグが増援。範囲攻撃で早めに処理する。

BOSS 3鯱牙のデェン

  1. 【ハイドロボール】ヘイト1位への前方扇。タンクはボス正面を味方へ向けない。
  2. 四隅の「怪しい水面」が泡立つと護衛が出現する。
  3. 泡立った水面を調べれば増援の出現を止められる。
  4. 増援が出た場合はタンクへ寄せて範囲攻撃で処理する。
  5. 現在は水面ギミックを無視してボス集中でも倒せることが多いが、初見では処理すると安全。

地下霊殿 タムタラの墓所

道中・進行のポイント

  1. 道中の目的は、各祭壇を守る敵を倒して【邪教の宝珠】を調べ、封印を順番に解除すること。
  2. 祭壇の敵を倒しただけで進まず、宝珠の調べ忘れがないか確認する。
  3. 最後の祭壇は最初から結界で閉じられている。奥側の敵を倒して解除用の宝珠を調べてから戻る。
  4. 単独で広く巡回する敵がいるため、ほかの敵グループを巡回ルート上で戦わせない。
  5. ボス前まで基本的には祭壇→宝珠→次の区画という流れ。分岐の奥へ宝箱目的で寄る必要はない。
  6. 最終ボスでボスと線で繋がった敵が出たら、その敵がボスを無敵化しているので最優先で倒す。

BOSS 1 / 2ヴォイド・ソウルカウンター

  1. 各中ボスは先に周囲の雑魚を倒すと、ヴォイド・ソウルカウンターが出現する。
  2. 【エンサンダー】通常攻撃へ雷属性ダメージを追加する強化。詠唱は中断可能。
  3. 【ダークオーブ】ヘイト1位への単体攻撃。タンクHPを確認する。
  4. 【コンデムネーション】前方扇範囲。タンク以外は正面へ立たない。
  5. 2回目以降も基本構成は同じなので、増援→本体の順に落ち着いて処理する。

BOSS 3絶対王ガルヴァンス

  1. 【マインドブラスト】ボス中心範囲＋麻痺。範囲外へ離れる。
  2. 【ドレインタッチ】ヘイト1位へ攻撃しつつボスが回復する。
  3. インプがボスと線で繋がるとガルヴァンスが無敵になる。
  4. 線で繋がったインプを最優先で倒して無敵を解除する。
  5. マイトリング／スケルトンも追加されるため、ボスだけを殴らず増援を処理する。

封鎖坑道 カッパーベル銅山

道中・進行のポイント

  1. パッチ6.1で大幅改修され、旧版の発破・スライム分裂・ボム誘爆を使った道中／ボス進行は現在は不要。
  2. 現行は基本一本道。雑魚を倒して進み、行き止まりで旧ギミック用アイテムを探す必要はない。
  3. 昇降機や扉など進行オブジェクトが出たら、周囲の敵を処理してから調べる。
  4. 初見は旧攻略動画より、現在表示される床予兆と通常の敵処理を優先する。

BOSS 1コットス

  1. 【グランドスラム】タンクへの強攻撃。タンクは防御バフ、他メンバーは正面を避ける。
  2. 【飛びかかり】複数の大きな円範囲。予兆が出てから余裕があるので安全地帯へ移動する。
  3. 連続円範囲は重なりを見て、外周へ追い込まれない位置を選ぶ。
  4. ボス正面へ戻らず、タンク以外は背面・側面を維持する。
  5. リニューアル後の現行版では旧ボム処理ではなく、通常の予兆回避で戦う。

BOSS 2イコラウス・アイル

  1. 【フルイドスプレッド】タンクへの強攻撃。防御バフを合わせる。
  2. ボスが分裂して小型スライムが出現したら、小型スライムの円範囲から離れる。
  3. 小型スライムの範囲がボス周辺へ重ならないよう、タンクは位置を調整する。
  4. 旧仕様の「ボムを爆発させてスライムを分裂」は現行版では使わない。
  5. 床予兆を優先して避けつつ本体へ攻撃を続ける。

BOSS 3豪腕のギュゲス

  1. 【グランドスラム】タンクへの強攻撃。防御バフを合わせる。
  2. 【ギガンティックスイング】広いドーナツ状範囲。ボス足元へ入って回避する。
  3. 壁際から雑魚が出現したら、タンクがまとめて敵視を取る。
  4. 雑魚処理中もギガンティックスイングの内側安置を見失わない。
  5. 旧仕様の壁破壊を待つ戦闘ではなく、現行版の予兆に従って処理する。

イフリート討伐戦

最重要ギミック

  1. 【炎獄の楔】が中央に出現したらボスより優先して破壊する。残したまま【地獄の火炎】を受けると全滅級。
  2. 【エラプション】は床の円形予兆から離れる。
  3. 履行後の【光輝の炎柱】は床予兆を見て、外周型なら内側、内側型なら外へ移動して回避する。
  4. タンクはイフリートを味方と逆向きにし、前方攻撃へ他メンバーを巻き込まない。
  1. 【インシネレート】正面扇。タンク以外はイフリート正面に立たない。
  2. 【バルカンバースト】ボス中心のノックバック。外周へ飛ばされないよう中央寄りで受ける。
  3. 【エラプション】足元に円範囲。予兆が出たら味方から離れて回避する。
  4. 【炎獄の楔】出現した楔を最優先で破壊する。
  5. 【地獄の火炎】楔破壊後の全体攻撃。軽減と回復を合わせる。

魔獣領域 ハラタリ修練所

道中・進行のポイント

  1. 開始直後から分岐があるが、基本はマップ上の進行方向へ沿って進み、行き止まりの寄り道は不要。
  2. 1ボス後は【鉄鎖のウインチ】を調べながら進む。宝箱または敵が出現する。
  3. ウインチから【ガスボム】が出た場合はすぐ自爆するので無理に追わない。【ライトニングスプライト】なら処理する。
  4. 2ボス戦ではボスが無敵になったら池の外へ出て、出現するライトニングスプライトを倒す。帯電中の水上に残らない。
  5. 2ボス撃破後は出現する【魔力の奔流】を利用して次の区画へ移動する。
  6. 最終ボスが炎の床を作って無敵化したら、外周のファイアスプライトを処理して無敵を解除する。

BOSS 1赤熱のブッシュファイア

  1. 【ファイア】単体魔法攻撃。タンクHPを確認する。
  2. HPを削ると外周の灯りからダムナトゥス／ノクシウスが出現する。
  3. 火の玉系の雑魚が中央へ到達すると大爆発するため、到達前に倒す。
  4. 雑魚は耐久が低いのでDPSだけでなくヒーラーも攻撃参加すると処理が早い。
  5. タンクは本体を維持しつつ、中央へ向かう雑魚を見失わない。

BOSS 2百雷のギーヴル

  1. 【レヴィンシャワー】前方扇範囲。タンク以外は正面を避ける。
  2. ボスが中央へ移動して発光すると無敵化の合図。
  3. 無敵中に水場へ入ると継続ダメージを受けるため、陸へ退避する。
  4. 無敵中は寄ってくるライトニングスプライトを優先して倒す。
  5. 【大放電】は水場を危険地帯にするため、中央移動を見たらすぐ陸へ。

BOSS 3獣闘士のタンガタ

  1. 【ストレートパンチ】ヘイト1位への強攻撃。タンクは防御バフを合わせる。
  2. 【バーニングウォード】でボスが無敵になったら、外周の灯りから来る火の精を倒す。
  3. 火の精がボスへ到達すると全体爆発につながるため最優先で処理する。
  4. 無敵が解除されるまで本体へ攻撃は通らないので、雑魚処理へ完全に切り替える。
  5. 同じ無敵フェーズが複数回あるため、毎回すぐ外周へ視線を移す。

監獄廃墟 トトラクの千獄

道中・進行のポイント

  1. パッチ6.1で道中が大幅改修され、現在はほぼ一本道。旧攻略にある【魔導フォトセル】集めは廃止されている。
  2. 旧版の分岐ルート・障壁解除・フォトセル不足で戻る、といった進行は現在は存在しない。
  3. 道を塞ぐクモの巣は付近の敵を倒せば消える。旧版のように巣そのものを攻撃する必要はない。
  4. 道中は前方範囲を味方へ向けない、床AoEを避ける、といった通常のID進行を優先すればよい。
  5. 最終ボスでは【グラフィアスの毒尾】が出現したら優先して破壊する。
  6. 【コチュー繭】は一定時間後に周囲へ毒液を撒くため、出現位置から距離を取る。

BOSS 1クァール・オ・ナインテイル

  1. 【アシッドミスト】ボス周囲の範囲攻撃。近くにいると毒を受ける。
  2. 詠唱／モーションを見たら近接も一度離れて回避する。
  3. 毒を受けた場合はヒーラーがエスナで解除できる。
  4. ボス正面に固まらず、側面・背面を基本位置にする。
  5. 1戦目は増援なし。アシッドミストだけ確実に避ければ安定する。

BOSS 2クァール・オ・ナインテイル

  1. 2戦目もボスはクァール・オ・ナインテイルで、別ボスではない。
  2. 【アシッドミスト】は1戦目と同じくボス周囲範囲＋毒。
  3. 2戦目はウォーデンズ・ウィップが2体追加される。
  4. 増援を先に範囲攻撃で処理し、被ダメージを増やさない。
  5. 増援処理後は1戦目と同様、アシッドミストを離れて回避する。

BOSS 3グラフィアス

  1. 【レルムシェイカー】ボス中心の円範囲。近接も範囲外へ離れる。
  2. 【シルクスクリーン】ランダム対象への直線範囲。味方を巻き込まない向きへ避ける。
  3. 【スティッキーウェブ】対象位置にフレッシーポッドを出す。
  4. フレッシーポッドは数秒後に爆発し、範囲ダメージ＋毒を与えるため離れる。
  5. 外周の緑床は移動速度低下を付与するため、中央寄りの安全な床を使う。

名門屋敷 ハウケタ御用邸

道中・進行のポイント

  1. 進行には【小さな鍵】を使う。最短ルートなら必要な小さな鍵は2個なので、すべての小部屋を探索する必要はない。
  2. 1ボス撃破後に【宿り木の鍵】を拾い、来た方向へ戻って【宿り木の扉】から地下へ進む。
  3. 地下では通路を回って【黄撫子の鍵】を回収し、【黄撫子の扉】を開けて2ボスへ。
  4. 2ボス撃破後に【血文字の紙片】を拾う。これが入口正面階段の封印解除に必要。
  5. 2ボス後は【魔力の奔流】（またはデジョン）で入口付近へ戻ると早い。正面階段を上がって封印結界を調べる。
  6. 結界先の御用邸の守衛を一定まで削ると最終ボスへの扉が開く。鍵を探して地下を再探索する必要はない。

BOSS 1夫人付きクラヴィジャー

  1. 【ヴォイド・ファイラ】ランダム対象の円範囲。予兆外へ移動する。
  2. 【ダークミスト】ボス中心円範囲＋恐怖。詠唱を見たら離れる。
  3. 【スウィート・スチール】予兆なしの前方扇。タンク以外は正面に立たない。
  4. ヴォイド・ファイラは遠隔も対象になるため、詠唱中に足元を確認する。
  5. ダークミストはスタンでも止められるが、基本は範囲外へ退避する。

BOSS 2御用邸の執事長＋御用邸の道化師

  1. 道化師の【アイススパイク】は反撃ダメージ＋スロウを付与する自己強化。
  2. 執事長の【ソウルドレイン】はボス中心範囲。近接も一度離れる。
  3. 道化師の方が柔らかく魔法攻撃も多いため、先に倒すと安定する。
  4. 2体をタンクが近くにまとめ、範囲攻撃で同時に削るのも有効。
  5. 氷棘の反射ダメージは小さいが、低HP時は無理に殴らず回復を優先する。

BOSS 3レディ・アマンディヌ

  1. 【妖異召喚】御用邸の守衛／夫人付きメイドを呼ぶ。出現した雑魚を優先処理。
  2. 守衛の視線攻撃は目アイコンへ背を向けて回避する。
  3. 【ビガイリングミスト】誘惑でボス側へ歩かされる。解除後すぐ守衛の視線から目を背ける。
  4. 【ヴォイド・サンダガ】タンク強攻撃。インタージェクト／ヘッドグレイズで中断可能。
  5. 【ダークミスト】ボス中心範囲＋恐怖。近接も詠唱を見たら離れる。

奪還支援 ブレイフロクスの野営地

道中・進行のポイント

  1. 開けたマップだが進行方向はほぼ決まっている。横へ大きく逸れると不要な敵を引っかけやすい。
  2. 道中のゴブリンが襲われている場所では周囲の敵を処理して救助し、先へ進む。
  3. 大型モンスターは前方攻撃を持つため、タンクは味方から向きを外す。
  4. 毒沼や危険床がある場所では、その場で戦わず安全な地面まで敵を引く。
