外郭攻略 カストルム・メリディアヌム

道中・進行

  1. 第1区画はタンクが先導し、出現する帝国兵を処理して魔導リーパー改へ進む。
  2. リーパー改の後は「ダストシュート」で移動。道中の円形予兆を避けながら雑魚を倒す。
  3. ヴァンガード戦後、シドが魔導アーマーで道を開く。通路を進みリウィア戦へ。

ボス1：魔導リーパー改

  1. 【高出力魔導レーザー】光った正面へ直線攻撃。ボスの向きを見て側面に外れる。
  2. 【増援要請】帝国兵が複数出現。タンクが敵視を取り、範囲攻撃で処理する。
  3. 【爆撃要請】全体攻撃が3回続く。軽減と回復を準備する。
  4. 【魔導カノン】対象の足元に円範囲。予兆を見て離れる。
  5. 開幕にも雑魚がいる。ボスの直線レーザーに注意しながら雑魚を優先して処理する。

ボス2：魔導ヴァンガード強襲型

  1. 【サーメットドリル】タンク強攻撃。防御バフを合わせる。
  2. 【気化爆弾投下要請】着弾地点からの距離減衰。マーカーから離れる。
  3. 【ハイパーチャージ】ボス中心の円とドーナツ範囲。両方の予兆の隙間へ入る。
  4. 【オーバーチャージ】前方扇に麻痺効果。距離減衰の後も正面を避ける。
  5. 【射撃要請】全員の足元に円範囲。予兆を避けた後のハイパーチャージにも備える。

ボス3：リウィア・サス・ユニウス

  1. 【魔導プラズマ】全体攻撃。軽減と回復を合わせる。
  2. 【無尽旋風斬】ボス中心の円の後、外周にも円範囲。最初の着弾後に安全地帯へ移る。
  3. 【アグライアクライム】タンク強攻撃。防御バフを合わせる。
  4. 【無限刃】連続する円・直線範囲。予兆の消えた場所へ順に移動する。
  5. 【炎獣心火撃→気化爆弾投下要請】8方向の直線を外したら中央へ寄り、外周4か所からの距離減衰を受ける。

確認資料：ゲームエイト／いまさら攻略FF14（6.1改修版）

最終決戦 魔導城プラエトリウム

道中・進行

  1. 第1区画は雑魚を処理し、魔導ターミナル・魔導トランスポーターを調べて移動。円形範囲予兆も避ける。
  2. コロッサス戦後は魔導アーマーに搭乗。魔導カノンなどで道中の敵を倒し、ネロ戦の前に降りる。
  3. ネロ戦後は隣の部屋の魔導ターミナルを調べてガイウス戦へ進む。

ボス1：魔導コロッサスII

  1. 【セルレアムベント】全体攻撃。軽減と回復を合わせる。
  2. 【試作魔導レーザーα】ボス周囲4方向の円から外側へさらに円が続く。最初の円同士の間を選ぶ。
  3. 【試作魔導レーザーβ】全員を対象に円範囲。重ならないよう散開する。
  4. 【グランドソード】ボス前方の扇範囲。正面から外れる。
  5. レーザーα・βの後にもグランドソードが来る。円を避けたらボスの向きも確認する。

ボス2：ネロ・トル・スカエウァ

  1. 【ミョルニルストライク】タンク強攻撃。防御バフを合わせる。
  2. 【ファイナルストライク】頭割り。対象の近くに集まって受ける。
  3. 【起動】線でつながる魔導デスクローが出現。線の対象は離れ、ほかの人が優先して倒す。
  4. 【ブーストアッパー】外周へ移動したネロが内側へ大きな扇範囲。ネロの近くへ寄って外す。
  5. 【オーバードライブ】中心から吹き飛ばし。外周のダメージ床に入らないようボス寄りで受ける。

ボス3：ガイウス・ヴァン・バエサル

  1. 【ターミナス・エスト／ファンタズマータ】青い剣撃と外周の幻影から直線範囲。剣の正面を避ける。
  2. 【イノセンス／フェスティナ・レンテ】前者はタンク強攻撃、後者は頭割り。対象に応じて防御か集合。
  3. 【ディーリゴー】円範囲が続けて出現。攻撃済みの位置を見て移動する。
  4. 【ハンド・オブ・ザ・エンパイア】全員に円範囲。ディーリゴーを避けた後に重ならず散開する。
  5. 【ウェニ・ウィディ・ウィキ】剣気100で即死。4体の幻影を優先して倒し、同時の範囲も避ける。

確認資料：ゲームエイト／いまさら攻略FF14（6.1改修版）

アルテマウェポン破壊作戦

進行

独立した道中のない討滅戦。前半の蛮神の力を使う戦闘から、後半のアルテマウェポン本体との戦闘へ移る。

前半：蛮神フェーズ

  1. 【蛮神固有の全体範囲攻撃】タイタンなどの力が解放される際に大きなダメージ。軽減と回復を合わせる。
  2. 【タイタン：距離減衰→ランドスライド】マーカーから離れ、続く2回の直線予兆を避ける。
  3. 【大地の重み】円範囲が2回続く。1回目の着弾跡へ移って次を避ける。
  4. 【ガルーダ：アイオブストーム】外周が使えない間は中央で円範囲を避け、出現したガルーダの位置を見る。
  5. 【イフリート：光輝の炎柱／ノックバック】2連続の円は着弾跡へ。吹き飛ばし後も外周の円範囲を避ける。

後半：アルテマウェポン

  1. 【誘導レーザー】タンク強攻撃。防御バフを合わせる。
  2. 【ホーミングレーザー】全員に円範囲。味方と重ならないよう散開する。
  3. 【エーテル波動】線で結ばれた玉が衝突する前に、片方の玉へ誰かが触れて処理する。
  4. 【収束レーザー／魔導フレア】前者は頭割りで集合、後者は全体攻撃なので軽減と回復を準備。
  5. 【アルテマ】詠唱完了までに倒す。たまるLB3をDPSが使い、詠唱中に削り切る。

確認資料：ゲームエイト（ノーマル）
