記憶幻想 アレクサンドリア

道中・進行

  1. 1ボスまでの城下町は雑魚を倒しながら進む。
  2. 1ボス後はいったん出発地点付近へ戻り、雷光大戦末期の別ルートを進む。
  3. 2ボス後は大戦後の城下町を進み、エリミネーター戦へ。

ボス1：抗体プログラムX

  1. 【イミューンリアクション】ボス前方か広い後方扇。予兆を見て側面へ移る。初回に外周が危険地帯になる。
  2. 【サーキットパージ】◯印の中心からドーナツ範囲。印の内側に入る。
  3. 【クロスパージ】＋印から十字範囲。5回分の印の出現順を見て、次の安全地帯へ近距離で移動。
  4. 【クゥランティン】タンクに円形強攻撃、別の1人へ頭割り。タンク以外の3人で集合する。
  5. 【サイタリシス／連続パージ】前者は全体攻撃。後者は途中に扇範囲が挟まるので各予兆の発動順を見る。

ボス2：アマルガム

  1. 【エレクトロウェーブ】全体攻撃。初回は外周も危険地帯になる。
  2. 【ディスアセンブリ→カレントマトリクス】分裂したボスが描く三角形の内部を避け、外へ移動。
  3. 【セントラルカレント／スプリットカレント】雷エフェクトの向きから直線攻撃が来る。表示方向を確認。
  4. 【アマルガムマイト／スーパーボルト】前者はタンク強攻撃、後者は頭割り。防御と集合を使い分ける。
  5. 【トライバースト】中心円から外へ広がる3連続攻撃。次の予兆で待ち、最初の着弾跡へ移る。

ボス3：エリミネーター

  1. 【パーティション／リコンフィグ・パーティション】剣がある側へ半面攻撃。持ち替え後の側を見る。
  2. 【サブルーチン】外周の手は直線攻撃、ビットはドーナツ範囲。剣の半面攻撃との重なりを見る。
  3. 【集雷針】エネルギー充填率100の前に6体を破壊。手とビットの範囲も避ける。
  4. 【エリミネーション】2本ずつ4回の直線攻撃。線が赤くなる順に発動するので、着弾跡へ移動。
  5. 【ディストーション→ライトネス・サルベイション】吹き飛ばし後は対象直線を重ねず散開し、続く半面攻撃に備える。

確認資料：いまさら攻略FF14／ゲームエイト

荒野秘境 サボテンダーバレー

道中・進行

  1. 最初の荒野は雑魚を倒し、バレルテンダーへ進む。
  2. 1ボス後は渓谷・水路を進んでアンスラサイト戦へ。
  3. 3ボス前の遺跡では番兵が光ると側面からビーム。壁に隠れて避ける。

ボス1：バレルテンダー

  1. 【パワーニードル】複数方向の扇予兆が詠唱終盤に広がる。最初から広い隙間の中央へ。
  2. 【バレルドロップ→バレルパワー】花付きサボテンの円は大きい。花なしの方向へ吹き飛ばされる。
  3. 【サイドパワーニードル】光った側に広い半面範囲。反対側の真横で待つ。
  4. 【バレルストンプ】対象者へ頭割り。全員で集合する。
  5. 【パワースマッシュ／パワーロア】前者はタンク強攻撃、後者は全体攻撃。防御と回復を準備。

ボス2：アンスラサイト

  1. 【アンスラボム：床】床に落ちたボムは周囲へ円範囲。ボムのない場所へ移る。
  2. 【アンスラボム：穴】穴に落ちると対応する側面の穴から直線攻撃。穴の印と射線を見る。
  3. 【アンスラカーニバル】円と直線の組合せが3回続く。次のボムの落下先も見て移動。
  4. 【アンスラボム：対象円】連続攻撃の最後に全員へ円範囲。重ねず散開する。
  5. 【コールバーナー／コールファイア】前者は頭割り、後者はタンク強攻撃。

ボス3：トラルの大蛇？

  1. 【小蛇呼び】小蛇が頭を前後に振れば直線、回せば小蛇中心の円。動きと印を見分ける。
  2. 【トラルの迷宮】矢印床で自動移動。◯印から逆算して入口を選び、×印を避ける。
  3. 【水蛇呼び→トラルの衝撃】3回の頭割りは全員で移動し、残るダメージ床を外周寄りに置く。
  4. 【トラルの洪水】角からの吹き飛ばし。直前のダメージ床へ飛ばされない位置を取る。
  5. 【トラルの落水】円予兆が順番に着弾。後から出た円で待ち、先の着弾跡へ移ってから散開。

確認資料：いまさら攻略FF14／エオルゼアデータベース（ボス名）

悪夢遊園 ストレイバロー

道中・進行

  1. 冒頭の街並みを進んでノッギン・ザ・ナイスヘッドへ。
  2. 1ボス後の遊園地区画は観覧車が倒れる円形予兆に注意する。
  3. 2ボス後は風船でお化け屋敷へ。最後のストレイ・ドール2体は範囲攻撃が続くので軽減を使う。

ボス1：ノッギン・ザ・ナイスヘッド

  1. 【ナイトメアフォール】頭が着地する円予兆から離れる。触れると行動不能などの弱体を受ける。
  2. 【チームスピリット→突撃命令】外周のナカマが走り回る。接触によるバインドを避ける。
  3. 【イービルスキーム】中央からX字・十字方向へ連続範囲。最初は外周の広い隙間で待つ。
  4. 【ナイトメアルーム】2人に追尾する5連続の円。対象はナカマを避けつつ動き続ける。
  5. 【スクリーム】扇が2方向ずつ3回。後の予兆で待ち、最初の攻撃跡へ移る。

ボス2：ジャック・イン・ザ・ポット

  1. 【ティーカップ→ティーアホワール】亡霊が入ったカップを目で追う。回転後そのカップから大きな円。
  2. 【ティーアホワール：2客】亡霊入りが隣同士か対角かを見て、停止後に両方の円を外す。
  3. 【ティーポット】紅茶を注がれたカップの円攻撃が3回続き、こぼれた場所がダメージ床になる。
  4. 【ラストドロップ】タンク強攻撃。防御バフを合わせる。
  5. 後半のカップは配置が増える。最初の線と回転後の位置を追い、予兆の出ない外側へ移る。

ボス3：トロイメライ

  1. 【ビターメモリーズ】ボスの光が1個なら中央、2個なら両側へ直線。光の数を確認する。
  2. 【ポルターガイスト→イービルソート】十字壁が出現。光る床で霊体化し壁を抜け、線を伸ばす。
  3. 【ゴーストダスター】円範囲の前に光る床を踏み、霊体化を解除して受ける。
  4. 【リビングスライサー】光る床で霊体化を付けて受ける。霊体化の有無を取り違えない。
  5. 【メモリアルパレード→ネガティブメモリーズ】幽霊の直線が出現順に来る。後の列で待ち、先の跡地へ。

確認資料：いまさら攻略FF14

廃地討究 ユウェヤーワータ

道中・進行

  1. 各区画の雑魚2グループを倒すと次のバリアが解除される。
  2. 手記をゆっくり読む場合は戦闘後にも戻って確認できる。

ボス1：リンドブルム・ザグナル

  1. 【広域放電】全体攻撃。軽減と回復を合わせる。
  2. 【牙を刺す】クリスタルへ突進した位置から複数の直線攻撃。先の着弾跡へ移る。
  3. 【放り投げ】投げ込み先を見て大きな着弾範囲から離れる。
  4. 【百雷】各自に追尾する円。重ならず移動する。
  5. 【牙を刺す→大放電】中央に出たエレクトロープ原石を詠唱前に倒し、途中の円範囲も避ける。

ボス2：所長カニロッカ

  1. 【ソウルリリース】大量の円が続けて出る。空いた場所で待ち、着弾跡へ順に移動。
  2. 【ファントムフラッド】ドーナツ範囲。ボスの足元へ入る。
  3. 【ダーラ】ボスから2回の扇範囲。交互に避け、最後の対象円は散開する。
  4. 【自失の叫び】心神喪失中は頭上の矢印が指す方向に動く。目押しで外周の細い通路へ。
  5. 【自失の叫び：距離減衰】中央の爆発までに最外周へ。黒い床へ触れないよう進む。

ボス3：ルニピャティ

  1. 【レイジングクロウ】ボスが向く方向への連続攻撃。背面へ回り込む。
  2. 【ラビットロープ：弧】線から順に爆発。広い隙間で最初を避け、着弾跡へ移る。
  3. 【ラビットロープ：渦】中心から外へ爆発。外で最初を避けて内へ移動する。
  4. 【クレーターカーヴ】中央が抜け落ちる。予兆を見て外周側へ。
  5. 【ビーストロア→レイジングクロウ】ボスからの距離減衰で対岸へ行き、回転する円を避けてから背面へ。

確認資料：ゲームエイト／ゲーム渉猟記（道中）

王城旧跡 アンダーキープ

道中・進行

  1. 2ボスから3ボスへ向かう道中のバイゴーン・ロードリッパーは扉付近まで移動して広い前方攻撃を使う。
  2. ロードリッパーの前方攻撃はタンクがスタンで止められる場合がある。

ボス1：ガルカント

  1. 【マイティサウンド】向いている側の半面攻撃。ターゲットサークルの矢印を見て背面へ。
  2. 【アンブッシュ】ボスが外周を走り、最後に止まった場所から前方直線。位置を見失わない。
  3. 【チリングチャープ】2か所の円範囲とマイティサウンドを同時に避ける。
  4. 【チリングチャープ後】さらに複数の円と各人の散開攻撃が来る。着弾後も重ならない。
  5. 【アースシング】土塊の円が出現順に発動。回避中のアンブッシュと半面攻撃にも注意。

ボス2：ソルジャーS

  1. 【イリュージョンハーフカット】幻影が残した光る側へ半面攻撃。最後の幻影を見る。
  2. 幻影が次々と消える間は、最初の位置で決めつけず、最後に残った位置を確認する。
  3. 【支援砲撃】線で結ばれた砲台から太い直線。砲台の正面を避ける。
  4. 【スラッシュウェーブ】ボスから各人へ扇形の散開攻撃。味方と重ならない。
  5. 砲撃とスラッシュウェーブが重なる時は、砲台の射線を避けられる場所で散開する。

ボス3：ヴァリア・ピラ

  1. 【起動指令】青球が線に沿って進み赤球に接触すると十字攻撃。接触先を見て射線を避ける。
  2. 【妖紅球移送】赤球が移動する。移動後の接触位置から十字を予測する。
  3. 【支援砲撃】外周で起動したタレット2基の正面から前方範囲。球と同時なら両方を見る。
  4. 【ヴァリアスパーク】ボスからの扇が後で広がる。広い隙間を使って各人の範囲を散らす。
  5. 【フロントニュートライズ】ボス正面の半面範囲と散開攻撃。背面側で重ならない。

確認資料：ゲームエイト

永久幽界 メインターミナル

道中・進行

  1. 最初の区画は行き止まり手前の分岐から進む。
  2. 1ボスの後は出現する雑魚を倒して、4体の処刑人との戦闘へ。
  3. 2ボスの後は再び雑魚を処理して大ボスへ進む。

ボス1：ある医療長の記憶

  1. 【広域散薬】全体攻撃。初回は外周が危険地帯になる。
  2. 【装置起動】緑はノックバック、橙は円。カウントダウンの付いた側から順に処理。
  3. 【知覚攪乱薬】後から加わる予兆は偽物。最初の正しい吹き飛ばし・円の位置を覚える。
  4. 【前面噴霧】前方半面範囲。ボスの背面へ回り込む。
  5. 【高圧縮薬弾】タンク強攻撃と解除可能な毒。タンクは防御、ヒーラーはエスナ。

ボス2：ある処刑人の記憶

  1. 【罪人捕捉】4体と各自1対1になる。線で結ばれた相手を攻撃し、円形の持ち場から出ない。
  2. 【足切りの刃】2段階の直線。2回目の刃側で待って1回目の着弾跡へ移る。
  3. 【断罪の雷剣→円月断／月輪断】動く雷剣を避け、続く中心円かドーナツの安全地帯へ。
  4. 【断罪の鉄球】3か所の鉄球から円。鉄球同士の隙間の外周へ移る。
  5. 【個別処理】タンクは破砕弾を沈黙、ヒーラーは死刑宣告をエスナ、DPSは焦熱刑具を破壊。

ボス3：ある人々の記憶

  1. 【メモリーズ：格子】人々と外周装置を結ぶ直線が2回。後から線が付いた側で待ち先の跡地へ。
  2. 【メモリーズ：円】大人数の幻影は大きな円、1人は小さい円。人の少ない側へ。
  3. 【ターモイル】振り上げた腕の側を半面攻撃。詠唱がないのでボスの腕を見る。
  4. 【インプレッション】円の処理後、1人の幻影がいる角へ斜めに吹き飛ばされる。外周は落下。
  5. 【メモリーズ：直線／メモリーストーム】人々が走る方向の直線を避け、頭割りは中央で集合。

確認資料：いまさら攻略FF14／ゲームエイト
