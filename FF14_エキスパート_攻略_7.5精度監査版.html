遺忘行路 ミストウェイク

道中・進行

  1. クワン洞の採掘区画を北へ進み、雑魚を倒してトレノ・カトブレパスの部屋へ。
  2. トレノ平野には落雷の円形範囲がある。予兆を踏まずにアムドゥシアスへ進む。
  3. トレノ市街地の雑魚を処理した先でサンダーグリフォンと戦う。

ボス1：トレノ・カトブレパス

  1. 【地震】全体攻撃。軽減・回復を合わせる。
  2. 【サンダラ】全員の円範囲を岩塊から離して捨てる。壊すと悪魔の光の遮蔽物が減る。
  3. 【悪魔の光】残った岩塊の陰へ入り、石化を防ぐ。
  4. 【サンダガ】タンク対象の円形強攻撃。タンクは味方と岩塊を巻き込まない。
  5. 【ライトニングレイ／ペトロブレス】前者は直線頭割りで集合、後者は石化する前方扇なので背面へ。

ボス2：アムドゥシアス

  1. 【サンダークラップコンチェルト】ボス前方か後方の広い扇。周囲の雷エフェクトが欠けた一角へ移る。
  2. 【バイオラ→サンダーギャロップ】緑の玉を出した後、5回突進。突進に触れた玉から円範囲が出る。
  3. 【サンダーギャロップ】最初の突進を外し、緑玉の1回目の爆発跡へ移って続く爆発を避ける。
  4. 【サンダジャ／ショックボルト】前者は全体攻撃と残った緑玉の爆発、後者はタンク強攻撃。
  5. 【サンダガ】3連続頭割り。途中で抜けずに集合し、回復を受ける。

ボス3：サンダーグリフォン

  1. 【サンダースパーク】全体攻撃のあと外周がダメージ床になる。中央寄りで戦う。
  2. 【ハイボルト→サンダリングロア】全員の円範囲を散開し、出た紫玉とボスの直線攻撃の交点を避ける。
  3. 【ゴールデンタロン】タンク強攻撃。防御バフを使う。
  4. 【ライトニングフォール】中央の突進直線を外して吹き飛ばしを受け、続く直線を避ける。
  5. 【ボルトストーム】外周を移動する竜巻が増える。次のサンダリングロアでは竜巻と紫玉の射線も確認。

確認資料：いまさら攻略FF14／さにすとのインベントリ

妖異侵攻 クルティウス魔導工廠

道中・進行

  1. バブイルの塔北側のコンメルキウム区を進み、雑魚を倒してアーマードアイ戦へ。
  2. 北エブラーナ林野の雑魚を処理した先でチョルトと戦う。
  3. 工廠内に入ったら緑色のパイプで先へ進み、マルファス戦へ向かう。

ボス1：アーマードアイ

  1. 【アイズオンミー】全体魔法攻撃。初回に外周がダメージ床となる。
  2. 【ペトリビーム】左右に揺れる照準が固定されたら、ボスの近くから逆側へ移動する。
  3. 【スキャナー発射】赤い動体感知エリア内は停止。移動・攻撃・回復・オートアタックも控える。
  4. 【質量弾ミサイル】対象者の頭割りへ集合する。
  5. 【ミサイル発射→ペトリビーム】床の円を2回避けてからボスへ近づき、最後の扇範囲を避ける。

ボス2：チョルト

  1. 【闇の衝撃】全体攻撃。初回は外周がダメージ床になる。
  2. 【肉弾】正面直線を避け、場外へ移ったボスの位置を追う。後半は追撃の直線が2回。
  3. 【肉圧殺・吹き飛ばし】肉弾の後に中央からノックバック。外周へ落ちない位置に戻る。
  4. 【嘔吐】対象者の方向へ扇範囲。ボスの側面・背面へ回り込む。
  5. 【肉圧殺・塔】頭割りの塔が4回続く。全員で順番に移動し、回復を挟む。

ボス3：マルファス

  1. 【ディスポーザル】全体攻撃。初回は外周にダメージ床が出る。
  2. 【ヴォイド・ダーク】対象者側の前方180度範囲。ボスの背面へ回る。
  3. 【スクラップメドル→パペットストリング】直線攻撃後、大型は扇、小型は自身中心の円範囲。操られた残骸の種類を見る。
  4. 【ストリングアップ】頭上カウント終了時に停止していると操られる。移動を続ける。
  5. 【パペットマスタリー】残骸が移動した後の攻撃範囲を見て避ける。大型の扇は根元側が狭い。

確認資料：いまさら攻略FF14／ゲームエイト
