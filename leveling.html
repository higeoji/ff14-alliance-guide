FF14 コンテンツルーレット：レベリング攻略

Lv15〜99のレベリング対象。ボス名・主要ギミック名を優先して5行で確認できる形式。

7.5時点のルーレット対象を基準に整理。攻略文は「ギミック名 → どう動くか」を優先。零式・極などルーレット外の内容は混在させない方針。

天然要害 サスタシャ浸食洞

ボス1：チョッパー

  1. 薄汚れたメモの色と同じ珊瑚を調べてスイッチを出す。
  2. チャージドホイスカー：ボス中心範囲を外へ避ける。
  3. 詠唱を見て早めに範囲外へ移動する。
  4. スタン可能なタイミングでは止めることもできる。
  5. 色ギミックを先に確認しておくと1ボスが安全。

ボス2：マディソン船長

  1. 1回目は大きなギミックがなく、基本的に攻撃を続ける。
  2. 2回目はHP半分以下でスカヴィ・ドッグ開放。
  3. タンクは檻から出た犬のヘイトをすぐ取る。
  4. 犬をまとめて処理し、ヒーラーへ流さない。
  5. 増援処理後は船長へ戻る。

ボス3：鯱牙のデェン

  1. ハイドロボール：ヘイト1位へ扇範囲。タンクは向きを管理する。
  2. 怪しい水面が泡立ったら調べてデェンの護衛出現を防ぐ。
  3. 水面ギミックを放置しない。
  4. 扇範囲は正面を避けて側面・背面へ。
  5. 追加敵を抑えれば安全に削れる。

地下霊殿 タムタラの墓所

ボス1〜2：ヴォイド・ソウルカウンター

  1. 2回出現するボス。基本は予兆を見て回避する。
  2. 周囲の雑魚を残しすぎない。
  3. タンクは敵をまとめ、ヒーラーは被弾を回復する。
  4. 詠唱中は無理に背面を取りに行かない。
  5. ギミック処理後に攻撃へ戻る。

ボス3：絶対王ガルヴァンス

  1. 召喚される雑魚を処理しながらボスを攻撃する。
  2. 全体攻撃後はHPを戻す。
  3. 床予兆を確認して範囲外へ移動する。
  4. 雑魚を放置すると被弾が増えるので優先処理。
  5. ボスだけを殴り続けず、増援を確認する。

封鎖坑道 カッパーベル銅山

  1. ボスの詠唱名と床の予兆を最優先で確認する。
  2. 頭割り・散開マーカーは、表示を見て集合か散開かを判断する。
  3. 連続ギミックは1回目を避けた直後に、次の予兆を確認する。
  4. 雑魚・装置・特殊オブジェクトが出たら、ボス攻撃より処理を優先する。
  5. ギミック処理後に安全な位置へ戻って攻撃を再開する。

魔獣領域 ハラタリ修練所

  1. 1ボス 赤熱のブッシュファイア：床のAoEを避け、増援が出たら処理。
  2. 2ボス 百雷のギーヴル：『雷撃』系の範囲を見て移動し、増援を優先処理。
  3. 3ボス 獣闘士のタンガタ：フィールドギミックと雑魚の出現を確認。
  4. 5か所の鉄鎖のウィンチは道中ギミック。ボス前に操作を忘れない。
  5. 低レベルIDなので、詠唱名→予兆→移動の順で見るだけでも被弾を減らせる。

  5. 道中は青い毒床・閉鎖扉などのギミック処理を優先する。
