旅神聖域 ワンダラーパレス

道中・進行のポイント

  1. 道中で【ランタンオイル】を拾い、扉を塞ぐ【錆びついた無限機構】を調べて開放しながら進む。
  2. ランタンオイルの拾い忘れがあると扉で止まるため、敵を倒した後に地面の進行アイテムを確認する。
  3. 徘徊する【トンベリ・ストーカー】は通常雑魚のように倒して進む相手ではない。近づかれる前に進行を優先する。
  4. 狭い通路でストーカーを避けながら戦うため、不要な寄り道や長時間の立ち止まりを避ける。
  5. 初見で迷った場合は『ランタンオイルを回収→錆びついた無限機構』が進行の基本と覚える。

BOSS 1キーパー・オブ・ヘリダム

  1. 【ビートダウン】タンクへの単体攻撃。タンクはHPを見て防御アクションを使う。
  2. 【モルディスニーズ】予兆なしの前方扇範囲。タンクはボスを外へ向け、ほかの3人は正面を避ける。
  3. 【インヘイル】対象方向へ扇状予兆と吸い込み。詠唱・扇の向きを見て横へ抜ける。
  4. 【グゥーブーグリーフ】インヘイルの直後にボス中心の毒付き範囲。吸い込みを避けたらボスから離れる。
  5. 【モルディフレム】対象の足元へ円範囲。味方と重ねず、床の予兆外へ移動する。

BOSS 2ジャイアント・ババロア

  1. 【ファイア】対象への攻撃。ヒーラーは対象のHPを戻し、タンクは後続の増援に備える。
  2. 【アモーフィックフレイル】ボス中心の円範囲。近接も予兆を見たら外へ出る。
  3. 【増援】色違いのババロアが複数出現。タンクが集め、DPSはボスより増援を優先する。
  4. 【回復する増援】ブルーババロアなど回復を使う個体を先に倒し、戦闘が長引くのを防ぐ。
  5. 【追跡】狙いを定められた人はボスから離れて走る。ほかの人は進路を空けて増援を処理する。

BOSS 3トンベリキング

  1. 【トンベリ・カッター】倒した数だけボスの「恨み」が増える。無計画にまとめて倒さない。
  2. 【みんなの恨み】恨みの蓄積で強くなるタンク対象攻撃。タンクは直前の恨み数を見て防御を合わせる。
  3. 【とぎたて／急所突き】タンクへの単体攻撃。ヒーラーは「みんなの恨み」の前後にHPを立て直す。
  4. 【トンベリ・スラッシャー】終盤に近づく増援。接近を避け、ボスの残HPが少なければ集中して決着させる。
  5. 【進行の優先順】必要なカッターだけ処理しつつボスを削る。恨みを増やしすぎないよう雑魚処理の量を調整する。

確認元：ワンダラーパレス攻略／技名・対処の照合

邪教排撃 古城アムダプール

道中・進行のポイント

  1. 最初の戦闘ではルナティック・プリーストを削るとサイコフレアが召喚される。召喚後はプリーストを処理してボスに移る。
  2. サイコフレアはリアニメイトで岩からマリオネットを呼ぶ。大型マリオネットが現れる奥側からボスを離すと接近を遅らせられる。
  3. デモンズウォールは戦闘床の左右が落下地点。開始前に中央へ寄り、リペルで横へ飛ばされないようにする。
  4. アナンタボガの部屋には遮蔽に使う石像がある。ボスの大技で石像が敵に変わるため、残っている石像を確認する。
  5. 大技の2回目以降は対象の位置に継続する円形攻撃も生まれる。石像の裏へ向かう通路に危険床を置かない。

BOSS 1サイコフレア

  1. 開始時のルナティック・プリーストを削るとサイコフレアが出現する。召喚後はプリーストを先に処理する。
  2. マインドメルトは全体攻撃。パーティのHPを戻し、カンカーで付く病気にも注意する。
  3. リアニメイトでボスと岩が紫の線で結ばれ、複数のマリオネットが出現する。線と出現位置を見る。
  4. 大型のメガリス・マリオネットが使うプレーンクラッカーは広い円形範囲。着弾範囲の外へ退く。
  5. ストーン・マリオネットのロックスライドは直線、マーブル・マリオネットのデモリッシュは全体攻撃。範囲を避けながら本体を削る。

BOSS 2デモンズウォール

  1. リクエファイは中央の直線範囲の後に左右の直線範囲が来る。まず側方へ、中央が消えたら中央へ移る。
  2. リクエファイを受けるとヘヴィが付く。続く範囲を避けづらくなるため、床の順序を見て動く。
  3. リペルは全体攻撃とノックバック。詠唱中にボスの正面中央へ寄り、橋の左右へ落ちない。
  4. マーダーホールはランダムな1名への攻撃。範囲回避後も各人のHPを確認する。
  5. 壁は奥から近づき戦闘床が狭まる。移動で攻撃を避けつつ本体を倒す。

BOSS 3アナンタボガ

  1. イミネント・カタストロフィーの詠唱中は、ボスと自分の間に石像を挟んで遮蔽する。
  2. 大技のたびに石像が1体ずつ敵に変わる。次に隠れられる石像の位置を確認する。
  3. 大技の2回目以降はランダムな対象の位置に円形の継続攻撃が生まれる。遮蔽地点から離して誘導する。
  4. テイルドライブはボス後方の広い扇範囲。背後へ居座らず、予兆を見たら側面へ避ける。
  5. ロトンブレスはタンク方向への予兆なしの扇範囲と病気。タンクは味方へ正面を向けない。

怪鳥巨塔 シリウス大灯台

道中・進行のポイント

  1. 道中に偏属性クリスタルが落下し、落下地点は継続してダメージを出す。敵をその場に留めず安全な床へ引く。
  2. サイモンド後にも偏属性クリスタルがある。クリスタルのそばに敵を固定せず、爆発範囲を避ける。
  3. ズーの部屋では外周の卵を範囲攻撃に巻き込まない。孵化前の破壊は母鳥の怒りを大きく増やす。
  4. ズーからタイラントへ進む道にはエーテル管のバルブが2か所ある。操作して進行する。
  5. セイレーン戦の前に回復と妨害技を確認する。死者の歌はHP全快で解除し、ルナティックボイスは中断できる。

BOSS 1浮沈のサイモンド

  1. コラプティングショットは前方範囲で偏属性クリスタルの蓄積を増やす。タンクは味方へ正面を向けない。
  2. クリスタルシャワーで東西に黄色い危険床ができる。踏み続けると蓄積が増えるので離れる。
  3. 偏属性クリスタルが3スタックすると爆発し被ダメージ上昇が付く。攻撃と危険床の重複を避ける。
  4. ボスのHPに応じて魅了された番犬が出る。雑魚が使うコラプティングスピットも蓄積を増やすので優先して倒す。
  5. ギガスラッシュは広い円形攻撃とノックバック。詠唱を止められる場合はスタンも有効。

BOSS 2ズー

  1. 外周の卵を孵化前に割ると母鳥の怒りが大きく増える。範囲攻撃に卵を巻き込まず、孵化後のヒナを処理する。
  2. 母鳥の怒りが高くなると狂乱で大きな範囲ダメージとスタンを受ける。怒りのスタックを増やしすぎない。
  3. ヒナと味方が線で結ばれたら、タンクは間の線を横切って対象を引き受けられる。
  4. ソニックブームは敵視1位への攻撃と裂傷。タンクのHPに注意する。
  5. ソニックストーム中はボスが上昇して無敵になり円形範囲を連続で撃つ。床を避けて着地を待つ。

BOSS 3タイラント

  1. このボスはHPが低い。増援へ過度に時間をかけず、ボスへの集中攻撃で短期決着を狙う。
  2. ウィップクラックは敵視1位への単体攻撃。タンクは敵視を維持しHPを確認する。
  3. エアロブラストは全体範囲にダメージと裂傷を付ける。使用が見えたら回復を用意する。
  4. エアロブラストはスタンで止められる。使用可能なら詠唱中に止める。
  5. 出現する雑魚はタンクが敵視を取り、ボスの攻撃を受ける味方を増やさない。

BOSS 4セイレーン

  1. 死者の歌のデバフは制限時間内に対象のHPを全快にすると消える。放置すると混乱して味方を攻撃する。
  2. ルナティックボイスは全体攻撃と回復効果低下。可能ならインタージェクトやヘッドグレイズで中断する。
  3. ボスが外周に現れたら強襲の直線突進。姿と進路を見て直線上から外れる。
  4. ボスが中央に現れたら亡者の歌の外側範囲に備え、ボス近くの安全地帯へ入る。
  5. 増援のゾンビ、とくに這うタイプは対象を拘束する。出たら優先して倒し、苦悶の歌の継続ダメージも回復する。

騒乱坑道 カッパーベル銅山(Hard)

道中・進行のポイント

  1. ヘカトン・マスターマインドの区間は一本道。入口側から床が燃えるため、敵視を取りつつ奥へ移動する。
  2. 1ボスではフランボーが奥から現れて燃えた床へ向かう。自爆前に優先して倒す。
  3. 2ボスまでに岩で道を塞がれ、周囲から雑魚が集まる部屋がある。タンクは新たに出た敵の敵視を取る。
  4. その部屋のボム系雑魚フルミネイターは自爆する。詠唱を見たら処理または範囲外への退避を優先する。
  5. 最終ボスの砂地ではアビスウォームが移動する。戦闘はなるべく砂地の外で行い、外周の結晶石へ近づけるようにする。

BOSS 1ヘカトン・マスターマインド

  1. ダークファイガの後、入口側から順に床がダメージエリアになる。戦闘を奥へ進める。
  2. フランボーは燃えた床へ進んで大爆発を狙う。見つけたら最優先で倒す。
  3. 奥側にも雑魚がいる。タンクは移動中に敵視を集めて味方への攻撃を防ぐ。
  4. ダークファイガは円形の予兆も出す。床の危険地帯から奥の安全地帯へ移る。
  5. ブリザドは単体攻撃。タンクのHPを保ちつつ、追加のフランボーを見落とさない。

BOSS 2ゴグマゴーレム

  1. 新型発破装置を調べ、出現した削岩爆弾をゴグマゴーレムの近くへ運んで爆発させる。
  2. 削岩爆弾は出現から十数秒で爆発し敵味方を傷つける。運搬したら自分は爆発範囲から離れる。
  3. ロックスライドはタンク方向の直線範囲。タンクは味方がいる方向へボスを向けない。
  4. 心核の輝きは対象位置に円形攻撃とダメージ床。対象は味方から離れ、着弾後に移動する。
  5. ブレーンクラッカーはボス中心の円形範囲。近接職も予兆を見て外へ出る。

BOSS 3復讐のウラノス

  1. 「アビスウォームがエサを探している」と表示されたら、外周の結晶石を砂地へ運ぶ。
  2. 結晶石を与えないとアビスウォームが大流砂を使う。大ダメージを防ぐため運搬を優先する。
  3. アビスウォームの進路に入るとサンドピラーを受ける。砂地の外側を使って移動する。
  4. パワーアタックは対象への円形範囲でヘヴィが付く。予兆が短いため表示後すぐ離れる。
  5. マキュリアルストライクはボス中心の円形範囲とノックバック。近接職は距離を取る。

妖異屋敷 ハウケタ御用邸(Hard)

道中・進行のポイント

  1. 開始地点は2階。敵を倒して小さな鍵を拾い、施錠された扉を開けて進む。
  2. 最初のボス前では扉付近の御用邸の石像を処理する。倒し残しを確認してから戦闘に入る。
  3. 道化師を倒した後は奥の妖しいオーブを調べて階を移動する。
  4. 1階の廊下ではランプのヴォイド・ファイガと追加の敵に注意し、危険な床に留まって戦わない。
  5. 扉の鍵を落とす敵を倒し、次の区画に進む。アッシュ戦では継続ダメージ床を安全地帯に重ねない。

BOSS 1御用邸の道化師

  1. ブリザドとヴォイド・ブリザガは敵視1位を狙う。タンクのHPを確認する。
  2. ヴォイド・ブリザドはランダムな1人を狙いスロウを付ける。対象のHPと状態異常に注意する。
  3. アイスフォールは詠唱なしの円形攻撃で着弾地点にダメージ床が残る。着弾後もその場から離れる。
  4. 魔法陣で倒した雑魚が復活する。タンクは敵視を取り直し、味方に向かわせない。
  5. 復活した雑魚をまとめて処理し、アイスフォールの床を踏まない位置で戦う。

BOSS 2アッシュ

  1. 処刑判決は4本の直線範囲が3種類の配置で現れる。予兆を見たら早めに空き地へ移る。
  2. アビサルスイングは敵視1位への予兆なしの前方扇範囲。タンクは味方の方へ正面を向けない。
  3. テネブラスミサイルはランダムな1人を狙い、着弾地点にダメージ床とヘヴィを残す。着弾後すぐ離れる。
  4. アビサルチャージは中央から5～8本の直線範囲。予兆線の間に入って避ける。
  5. アビサルトランスフィクションはランダムな1人に麻痺を付ける。回復役は対象を確認する。

BOSS 3ハリカルナッソス

  1. ヴォイド・ファイラはランダムな1人への円形範囲。対象はほかの味方と重ねない。
